# AI Companion Chat

Please build a complete Chat Web Application named "الغباء الصناعي" (ChatGhabiy). This focusing on the AI Chat engine and the Social/Friends features.

Requirements to implement:

1. Complete UI Layout with Multi-language (Arabic RTL / English LTR) and Themes (Light/Dark).

- Sidebar containing: 🤖 محادثة جديدة, 💬 محادثاتي, 👥 الأصدقاء, 🔔 طلبات الصداقة, 👤 حسابي, ⚙️ الإعدادات.

2. AI Chat System ("🤖 محادثة جديدة"):

- A functional chat window where users can text an AI assistant.

- Provide real-time simulated responses.

- Next to each AI message, add buttons for: "نسخ الإجابة" (Copy) and "مشاركة" (Share).

- Support markdown for code and text formatting.

- Add an attachments button placeholder (for uploading images/files later).

- "💬 محادثاتي": Users can see active chats, continue them, delete them, or rename them. Add a search bar to search chat titles.

3. Social & Friends System ("👥 الأصدقاء" & "🔔 طلبات الصداقة"):

- In the Friends section, add a search bar to "البحث عن مستخدم" (Search users).

- Add functionality to: إرسال طلب صداقة (Send request), قبول (Accept), رفض (Reject), حذف صديق (Remove friend), and حظر مستخدم (Block user).

- Display a list of current friends with their online/offline connection status (مشاهدة حالة الاتصال).

Please ensure the code is highly structured, modern, and ready for local download later.
